# 🎮 One Minute Trader
**장르:** 캐주얼 예측 게임  
**플랫폼:** 모바일 (Flutter WebView + Phaser 3)  
**플레이타임:** 1분  
**타깃 유저:** 코인 차트를 좋아하지만 진짜 돈은 쓰고 싶지 않은 사람들 😂  

---

## 💡 콘셉트 요약

플레이어는 1분 동안 비트코인, 이더리움, 솔라나 등 주요 코인 중 하나를 선택하고,  
해당 코인의 **시세가 오를지 내릴지**를 예측한다.  
실제 거래는 없고, **랜덤 + 패턴 기반 가상 시세 그래프**가 표시된다.  
정확히 예측할수록 점수를 얻고, 틀리면 감점된다.  
연속 성공 시 **콤보 보너스**가 붙는다.  

👉 *느낌상 “코인 버전의 하이로우 게임 + 실시간 차트 느낌”*

---

## 🕹️ 핵심 플레이 루프

1️⃣ **코인 선택 화면**  
- BTC, ETH, SOL 중 하나 선택  
- 코인별로 색상/그래프 테마 다름  
  - BTC = 노란색  
  - ETH = 파란색  
  - SOL = 보라색  

2️⃣ **시세 시뮬레이션 시작 (Phaser 씬 전환)**  
- 그래프가 실시간으로 위/아래로 랜덤 움직임  
- 그래프는 Phaser의 tween 또는 particle 기반 애니메이션으로 표현  

3️⃣ **플레이어 입력 (Up / Down 버튼)**  
- 버튼 누르는 순간, 예측이 잠금됨  
- 이후 약 5초 동안 차트가 추가로 움직임  

4️⃣ **결과 공개**  
- 그래프가 상승 마감 → Up 성공  
- 그래프가 하락 마감 → Down 성공  
- 맞추면 +10점, 틀리면 -5점  
- 3회 연속 성공 시 콤보 배율 ×1.5  

5️⃣ **다음 라운드로 자동 이동**  
- 총 60초 타이머가 돌아가며 자동 진행  
- 남은 시간/점수 표시  

6️⃣ **게임 종료 요약화면**  
- 총 점수 / 정확도 / 최고 콤보 표시  
- 다시하기 버튼

## ⏱️ 플레이 타임 구조

| 구간 | 설명 | 시간 |
|------|------|------|
| 코인 선택 | BTC / ETH / SOL 중 선택 | 5초 |
| 예측 라운드 (12회 × 5초) | 1회당 Up/Down 결정 → 결과 표시 | 60초 |
| 결과 화면 | 점수 요약 | 5초 |

총 플레이타임 약 1분 10초 내외.

## 🎨 비주얼 & 연출

- **Phaser Canvas (480×800 기준)**  
- 그래프는 단순한 line chart 애니메이션 (sin 파형 + 노이즈 섞기)  
- 상승 시 초록색, 하락 시 빨간색  
- 성공 시 텍스트 “+10 🚀”  
- 실패 시 “-5 💥”  
- 배경: 네온 블루/퍼플 톤으로 코인 마켓 분위기  
- Flutter 상단에는 코인 심볼 아이콘 + 잔여 시간 표시

## 🧠 점수 시스템

| 행동 | 점수 | 추가 설명 |
|------|------|-----------|
| 예측 성공 | +10 | 기본 |
| 예측 실패 | -5 | 기본 |
| 3연속 성공 | ×1.5 보너스 | 15점 |
| 5연속 성공 | ×2 보너스 | 20점 |

> 점수는 Phaser 내부에서 관리하고, Flutter WebView로 전달 (`window.flutter_inappwebview.callHandler('updateScore', score)` 형태)
