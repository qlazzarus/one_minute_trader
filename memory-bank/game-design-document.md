# 🎮 One Minute Trader
**장르:** 캐주얼 예측 게임  
**플랫폼:** 모바일 (Flutter WebView + Phaser 3)  
**플레이타임:** 1분  
**타깃 유저:** 코인 차트를 좋아하지만 진짜 돈은 쓰고 싶지 않은 사람들 😂  

---

## 💡 콘셉트 요약
플레이어는 1분 동안 비트코인, 이더리움, 솔라나 등 주요 코인 중 하나를 선택하고,  
해당 코인의 **시세가 오를지 내릴지**를 예측한다.  
실제 거래는 없고, **랜덤 + 패턴 기반 가상 시세 그래프**가 표시된다.  
정확히 예측할수록 보상을 얻고, 틀리면 손실된다.  
연속 성공 시 **콤보 보너스**가 붙는다.  

👉 *느낌상 “코인 버전의 하이로우 게임 + 실시간 차트 느낌”*

| 단계 | 설명 |
|------|------|

| 6️⃣ 결과 요약 | 총 코인 획득량, 콤보 수, 정확도 표시 |

## 🎨 비주얼 & 연출
- **Phaser Canvas (480×800 기준)**  
- 차트: sin+noise 기반 라인 애니메이션  
- 상승 = 초록 / 하락 = 빨강  
- 성공 시 “+10 🚀”, 실패 시 “-5 💥” 텍스트  
- 배경: 네온 블루/퍼플 코인마켓 분위기  
- Flutter: 상단에 코인 심볼 및 잔여 시간 표시

## 🪙 알고리즘 개요
- 5초 단위 랜덤 시세 변화 (sin + noise)  
- 기본 상승/하락 확률 50:50  
- 콤보 유지 시 난이도 상승 (하락 확률 증가)  
- 그래프는 Phaser Tween 기반

## 🗓️ Development Milestones

### 🧩 Phase 1 — Core Trading Mode
- 12라운드 × 5초 → 1분 트레이딩 구조 완성  
- 점수 → 코인 보상 전환 (BTC / ETH / SOL)  
- HUD에 코인 잔고 표시  
- 콤보 효과 및 시각 피드백 강화  
- 결과화면에서 획득 요약 표시  

### 🧱 Phase 1.3 — Main Menu Rebuild
- 모드 선택 허브 구축 (Phaser 3 씬)  
- Trading / Mining / Mining Farm 모드로 분기  
- Bibi 모드별 대사 및 애니메이션 추가  
- 공용 Wallet 표시  

### ⚙️ Phase 1.6 — Multi-Mode Bootstrapping
- **Mining Mode (탭 채굴):** 탭 시 코인 생성, 쿨타임 제한  
- **Mining Farm Mode (자동 채굴):** 장비 구매 및 업그레이드, Idle 수익  

### 💰 Phase 2 — Reward & Wallet Integration
- 모드 간 자산 공유 및 Flutter ↔ Phaser 데이터 동기화  
- 에어드롭 및 리워드 데이터 통합  

### 🧠 Phase 3 — Crypto Lab
- 코인 교환, 업그레이드, Bibi AI 강화  
- 장기 성장 구조 도입  

### 🎯 Phase 4 — Retention Features
- Daily Bonus, Leaderboard, Missions  
- Cosmetic Unlocks (스킨, 테마 등)  

### 💵 Phase 5 — Airdrop System
- 매일 1회 무료 에어드롭  
- 광고 시청 시 추가 2회 가능 (최대 3회/일)  
- Bibi 대사 및 사운드 피드백  

### 🧩 Phase 6 — Monetization & Expansion
- 광고 기반 보상형 루프 확장  
- 채굴 및 업그레이드 수익화 강화  
- 리트라이 / 시간 연장 광고 등 다양한 수익 구조  
- 게임 내 경제 시스템 확장 (거래소, 강화 등)
