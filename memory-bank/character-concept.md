# 🧍 캐릭터 콘셉트 — “비비 (Bibi)”

## 캐릭터 개요
- 이름: **비비 (Bibi)**  
- 성격: 장난기 많고, 가끔 허세 섞인 코인 덕후  
- 역할: 플레이어에게 말을 걸며 게임 진행을 돕는 “코인 요정”  
- 비주얼: 코인 모양의 머리핀 + 네온 재킷을 입은 2D 캐릭터

## UI 내 위치
- 게임 상단 좌측, 말풍선으로 반응 표시
- Phaser 내 sprite로 배치 (`CharacterDisplay.js`)

## 예시 반응
| 상황 | 대사 |
|------|------|
| 첫 시작 | “오늘도 한탕 노려볼까?” |
| Up 선택 시 | “올라간다, 올라가~!” |
| Down 선택 시 | “하락장엔 쇼트지~” |
| 연속 성공 | “이건 그냥 예언자 수준인데?” |
| 실패 | “손절각이다…” |

## 확장 아이디어
- 표정 애니메이션 (눈 깜빡임, 웃음)
- 음성 + 텍스트 동기화
- 향후 스킨 시스템 (Bibi, Pepe, Satoshi 등)
